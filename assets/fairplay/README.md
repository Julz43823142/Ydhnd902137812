# Offline opening reference

`opening-lines.json` derives legal UCI lines from the five TSV files in
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings).
The source revision and CC0-1.0 dedication are recorded in the JSON. The source
describes these opening facts as public domain and dedicates any database
copyright to [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

No player games, cases, identities or analytical labels are included. This is a
curated named-opening reference, not an exhaustive opening-theory database.
Missing entries mean **unrecognized**, not proof that a move is novel. Reference
failure uses the conservative legacy opening protection without network access.
